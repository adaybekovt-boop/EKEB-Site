═══════════════════════════════════════════════════════════════════
   ЕКЕБ — деплой на Cloudflare Pages
═══════════════════════════════════════════════════════════════════

Проект собран как СТАТИЧЕСКИЙ САЙТ (next.config.mjs → output: "export").
Готовая сборка лежит в папке  /out/  — это полностью самодостаточный
набор HTML + CSS + JS + ассетов. Сервер не нужен.

У вас два пути загрузки. Выберите один.


───────────────────────────────────────────────────────────────────
ПУТЬ 1.  БЫСТРЫЙ — Drag & Drop папки /out/
───────────────────────────────────────────────────────────────────

1. Откройте  https://dash.cloudflare.com
2. В левом меню выберите  Workers & Pages  →  Create
3. Перейдите на вкладку  Pages  →  Upload assets
4. Введите имя проекта (например  ekeb )  →  Create project
5. Перетащите содержимое папки  /out/  целиком в зону загрузки.
   ВАЖНО: перетаскивать нужно ВНУТРЕННОСТИ /out/, а не саму папку.
   То есть на экране должно стартовать с index.html, _next/, и т.д.
6. Нажмите  Deploy site
7. Через 30–60 секунд получите ссылку вида
   https://ekeb.pages.dev

Всё. Сайт работает.

Чтобы обновить сайт позже — нажмите  Create new deployment  и снова
загрузите свежий /out/.


───────────────────────────────────────────────────────────────────
ПУТЬ 2.  АВТОДЕПЛОЙ — Git + Cloudflare сам собирает
───────────────────────────────────────────────────────────────────

Подходит если планируете часто менять сайт.

1. Создайте репозиторий на GitHub (private или public — без разницы).
2. Запушьте всё содержимое этой папки В РЕПО.
   ВАЖНО: не пушьте  /out/  и  /node_modules/  — Cloudflare сам их
   соберёт. В корне уже лежит  .gitignore , он это учитывает.
3. На  dash.cloudflare.com  →  Workers & Pages  →  Create  →  Pages
   →  Connect to Git
4. Выберите ваш репозиторий.
5. Build settings:
        Framework preset:    Next.js (Static HTML Export)
        Build command:       npm run build
        Build output dir:    out
        Root directory:      /
        Node version:        20
6. Environment variables — НЕ нужны, проект без секретов.
7. Save and Deploy.

Cloudflare выполнит  npm install  →  npm run build  → выложит /out/.
Каждый  git push  в main будет автоматически пересобирать сайт.


───────────────────────────────────────────────────────────────────
ВОЗМОЖНЫЕ ОШИБКИ
───────────────────────────────────────────────────────────────────

* "404 после открытия любой подстраницы"
  В Cloudflare Pages → Settings → Builds & Deployments → внизу есть
  раздел  Pages Functions . Проверьте, что НЕТ файла  _routes.json
  с особыми правилами. Если есть — удалите.
  Также убедитесь, что в next.config.mjs стоит  trailingSlash: true
  (он стоит).

* "Build failed: command not found: next"
  Cloudflare использует устаревший Node. Зайдите в
  Settings → Environment variables → Add → имя  NODE_VERSION ,
  значение  20  →  Save .

* "Images broken / 404 на /_next/image"
  Не должно быть — статический экспорт уже отключил next/image
  оптимизацию (unoptimized: true). Если всё-таки — пересоберите
  заново (Path 1: перетащите свежий /out/).

* "Кириллица в URL ломается на /about/staff/учитель..."
  Не используется — все роуты на латинице. Если когда-то
  понадобятся — Cloudflare Pages кириллицу в путях не любит,
  заменяйте на транслит.

* "Site loaded но без шрифтов / стилей"
  Откройте DevTools → Network. Если 404 на /_next/static/css/...
  — значит вы загрузили НЕ ВНУТРЕННОСТИ папки /out/, а саму /out/
  как корень. Удалите деплой и перезалейте, выделив всё ВНУТРИ /out/.


───────────────────────────────────────────────────────────────────
ЛОКАЛЬНЫЙ ЗАПУСК (если понадобится снова открыть локально)
───────────────────────────────────────────────────────────────────

   npm install
   npm run dev

Сайт поднимется на http://localhost:3000 (или можно указать
порт:  npx next dev -p 5317 ).

Чтобы пересобрать /out/ перед загрузкой на CF:

   npm run build

Готовый сайт окажется в /out/.


───────────────────────────────────────────────────────────────────
КАСТОМНЫЙ ДОМЕН (опционально)
───────────────────────────────────────────────────────────────────

После деплоя на pages.dev:
1. На странице проекта  Custom domains  →  Set up a custom domain
2. Введите  ekeb.edu.kz  (или ваш)
3. Cloudflare покажет DNS-запись (CNAME), которую нужно прописать
   у регистратора домена.
4. После прописывания  ↻  Verify  → подождать пропагацию
   (обычно 5–30 мин).

   надо — значит сборка ок и проблема только в CF-настройках.
